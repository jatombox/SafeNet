# SafeNet — Plataforma de educación y prevención sobre seguridad digital

Proyecto académico (Ingeniería Informática). HTML5 + CSS3 + JavaScript, sin frameworks.

## Cómo verlo
1. Abre la carpeta en VS Code.
2. Abre `index.html` en el navegador (recomendado: extensión **Live Server**).

## Estructura
- `index.html` — estructura y secciones.
- `css/style.css` — diseño y responsive.
- `js/app.js` — navegación, temas de "Aprende", "¿Qué hago si me pasó?" y recursos.
- `js/scams.js` — juego "Detecta una estafa" (6 escenarios ficticios educativos).
- `js/quiz.js` — cuestionario de 10 preguntas con puntuación y nivel.
- `assets/images/` — ilustración del hero.

Para editar contenido, modifica los arreglos `TEMAS`, `SITUACIONES`, `RECURSOS`, `ESCENARIOS` y `PREGUNTAS`.
